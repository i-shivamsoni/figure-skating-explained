# Security policy

Figure Skating Explained is a static site: it has no accounts, no server-side state and no
backend of its own. The only data it stores is the visitor's own theme and skater preferences
in their browser's `localStorage`. Vercel Web Analytics collects aggregate page-view counts
without cookies or personal identifiers.

If you find a security problem (for example in a dependency, the build, or a way to run code
through a URL parameter), please report it privately through GitHub's "Report a vulnerability"
button on the repository's Security tab rather than in a public issue. You should hear back
within a week. Problems in dependencies are also picked up by Dependabot.
